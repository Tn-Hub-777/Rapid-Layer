# Giraj Editable Catalog

Audience: prospective customers, collaborators, and anyone reviewing recent 3D-printing work.

Objective: create a clean, portfolio-style catalog that can be imported into Canva and still keep text and photo elements editable.

Assumptions:
- The startup name is inferred as `Giraj` from the logo-style text visible in `IMG-20260417-WA0091.jpg`.
- Cover copy should stay editable so the startup name, description, and materials can be changed later inside Canva.
- The catalog should use a curated image selection rather than every near-duplicate photo, to keep the layout polished and readable.

Slide plan:
1. Cover page with editable startup name, description, and material pills, plus a brand image and hero work strip.
2. Featured Builds page with the strongest mixed-category work samples for fast visual impact.
3. Functional Parts & Fixtures page focused on brackets, holders, trays, and engineering-oriented pieces.
4. Models & Miniatures page focused on character prints, articulated pieces, and showcase models.
5. Assemblies & Surface Details page focused on grouped parts, surface finish, and kit-style product presentation.

Editability plan:
- All headings, descriptive copy, and material labels are separate text boxes.
- Every photo is placed as its own image object.
- The final file is exported as PPTX so it can be imported into Canva with editable components.
